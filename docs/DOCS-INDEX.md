## 📚 Resumen de fuentes citadas en `docs/`

- **`*.md` generados en commits del repo** → canónicos, versionados.
- **`*.md` traídos de Desktop (Claude)** → referencia, ya versionados
  tras commit. NO se actualizan en Desktop automáticamente (son snapshot
  del estado al sync).
- **`*.pdf` y `*.html` mockup** → snapshots / artefactos finales.
- **`*.xlsx` y `*.pdf` de outputs** → entregables al cliente, snapshot.

> **Regla de oro:** si un doc está en este `docs/`, es porque se ha
> decidido conscientemente traerlo al repo (no se versionan archivos
> personales o que se regeneren automáticamente).
