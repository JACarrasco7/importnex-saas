# Trampas y fuentes problemáticas

> Anti-bots, páginas que no cargan, proveedores fantasma, precios que cambian.
> Anotar SIEMPRE que una fuente falle o engañe (reglas E3/E10) para no repetir el intento.

Formato:

```
## YYYY-MM-DD · <fuente/sitio>
- Qué pasó: ...
- Workaround: ... (o "ninguno, degradar a <alternativa>")
```

(vacío — se llena con el primer uso)
