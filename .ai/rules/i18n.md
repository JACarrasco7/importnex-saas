# i18n Rules — es/en sincronizado

> Activar por glob: `resources/lang/**`, `resources/js/i18n/**`, cualquier string visible.

---

## Regla de paridad

**Toda clave nueva DEBE existir en `es` y `en` simultáneamente.** Script `node scripts/check-translations.cjs` lo valida en CI.

## Backend (Blade)

```php
// resources/lang/es/cars.php
return [
    'create' => [
        'title' => 'Crear coche',
    ],
];
```

```blade
{{ __('cars.create.title') }}
```

## Frontend (Vue 3)

```js
// resources/js/i18n/es.js
export default {
    cars: { create: { title: 'Crear coche' } },
};
```

```vue
<script setup>
import { useTranslations } from '@/Composables/useTranslations';
const { t } = useTranslations();
</script>
<template>
    <h1>{{ t('cars.create.title') }}</h1>
</template>
```

## Estructura de namespaces

```
common.*       → Botones, acciones, errores genéricos
nav.*          → Sidebar/menú
cars.*         → Módulo coches
clients.*      → Módulo clientes
billing.*      → Suscripciones, planes
errors.*       → 401, 403, 404, 500, validation
emails.*       → Subject + body de emails
flash.*        → Toasts in-app
alerts.*       → Notificaciones/alertas
pricing.*      → Planes y precios (público)
```

## Interpolación

- **`{variable}`** (no `${var}`, no `%var%`).
- Para Vue: `{('cars.count') :count}` con datos pasados a `t()`.

## Plurales

**Backend Laravel style** (en archivos PHP `resources/lang/`):
```php
'apples' => '{0} Sin manzanas|{1} Una manzana|[2,*] :count manzanas',
```

**Frontend dos formas equivalentes** (soportadas en `t()` desde 2026-08-07):

1. **Laravel pipes** (sintaxis clásica):
```js
alerts: { count_short: "{count} alerta | {count} alertas" }
```
`t('alerts.count_short', { count: 1 })` → "1 alerta"

2. **Object form `_one` / `_other`** (preferida para plurales complejos):
```js
app: { inventory_count: { _one: ":count vehículo en su flota", _other: ":count vehículos en su flota" } }
```
`t('app.inventory_count', { count: 1 })` → "1 vehículo en su flota"
`t('app.inventory_count', { count: 5 })` → "5 vehículos en su flota"

Sin `replacements.count` y valor objeto → cae al `_other` o primer valor.

## CI script

```bash
node scripts/check-translations.cjs       # paridad es/en
node scripts/check-untranslated.cjs       # strings hardcoded
```

Si falla el primero: clave sin contraparte.
Si falla el segundo: string visible debe moverse a i18n.

## NO HACER

- ❌ `'Guardar'` hardcoded en Vue.
- ❌ `{{ __('key') }}` en Vue (eso es Blade).
- ❌ Añadir clave solo en `es.js`.
- ❌ Usar `messages.en` (usar `lang/en/`, convención Laravel).
- ❌ `new Date().toLocaleString()` sin locale explícito.
- ❌ `:placeholder` o `TODO` en una clave.
- ❌ Interpolación `${var}` o `%var%`.
